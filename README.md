# FlutterLab1

Консольное приложение «Анализатор оценок» на языке Dart. Программа обрабатывает списки оценок студентов, высчитывает средний балл, минимальные и максимальные значения, а также определяет общую статистику успеваемости.

## Запуск
1. Клонировать репозиторий: `git clone <url_вашего_репозитория>`
2. Перейти в папку проекта: `cd lab1_dart`
3. Установить зависимости: `dart pub get`
4. Запустить: `dart run`

## Ответы на вопросы

### 1. Чем статическая типизация Dart отличается от Python? Какое практическое преимущество она даёт?
В Python применяется динамическая типизация (тип проверяется во время выполнения), а в Dart — **статическая строгая типизация** (тип известен уже на этапе компиляции). 
* **Преимущество:** Компилятор Dart отлавливает огромный класс ошибок до запуска кода (runtime). Это повышает надежность, ускоряет работу программы и улучшает автодополнение (IntelliSense) в IDE.

### 2. Что означает String?? Чем отличается от String?
* `String` гарантирует, что переменная **никогда не может быть null**.
* `String?` (с вопросительным знаком) объявляет **nullable-тип**, разрешая переменной принимать значение `null`. 
* Ошибка синтаксиса `String??` — это некорректная запись, компилятор её не пропустит (не путать с бинарным оператором `??` для подстановки дефолтного значения).

### 3. Зачем в Dart final, если в Python можно просто договориться не менять переменную?
В Python нет встроенной защиты на уровне языка, и программист может случайно перезаписать «неизменяемое» значение. В Dart ключевое слово `final` защищает переменную на уровне компилятора: при попытке повторного присвоения программа просто не скомпилируется, исключая человеческий фактор.

### 4. Чем именованный параметр {required String name} отличается от позиционного? Приведите пример вызова.
* **Позиционные параметры** передаются строго по порядку их объявления (например, `greet("Артём")`).
* **Именованные параметры** `{}` передаются по имени в любом порядке, что делает вызовы функций с большим числом аргументов читаемыми. Модификатор `required` обязывает передать этот параметр при вызове (иначе будет ошибка компиляции).
* **Пример вызова:** `printStats(name: 'Артём Иванов', grades: [5, 4, 5]);`
